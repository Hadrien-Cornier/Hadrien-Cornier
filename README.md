# Hi, I'm Hadrien

My background is in software, data, and production ML. I'm now focusing on robotics, especially data, evaluation, and machine learning. How do we collect useful robot data, and how do we check whether a policy improves?

I learn by implementing recent papers and trying things on a robot. It helps me understand how the ideas work and where I still have questions.

## Breaking Bellman

<a href="https://hadrien-cornier.github.io/breaking-bellman/"><img src="assets/breaking-bellman-logo.png" width="96" alt="Rover robot"></a>

[Breaking Bellman](https://hadrien-cornier.github.io/breaking-bellman/) is an experiment in learning faster with AI through interaction. You make guesses, test them in small reinforcement learning games, and see what happens. AI help is optional. I'm exploring whether this makes the concepts easier to understand. [Source](https://github.com/Hadrien-Cornier/breaking-bellman).
